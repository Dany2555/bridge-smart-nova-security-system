## Smart Security Alarm System

This project is a simple home security system built using an Arduino Uno R3. It detects intruders using a push button (simulating a door sensor), activates an alarm with a buzzer and red LED, and allows system reset using another button.

A green LED shows normal monitoring, while an LDR sensor enables night mode by detecting darkness.

### Features
- Intruder detection
- Alarm system (LED + buzzer)
- Reset functionality
- Night mode using LDR
- Serial monitor messages

### Components
- Arduino Uno R3
- LEDs (Red & Green)
- Push buttons (x2)
- Buzzer
- LDR sensor
- Resistors
